🚀 快速上手（7 步）

  1. 录入食材库：在「食材采购」页添加食材，填写分类、采购单价、损耗率、净料率等；净料成本自动算出。
  2. 录入场地成本：在「场地成本」页填写租金、物业、水电、装修摊销与营业天数。
  3. 录入人力成本：在「人力成本」页按岗位添加人数、月薪、社保公积金比例与各项补贴。
  4. 录入厨房设备：在「厨房设备」页添加设备清单，自动汇总一次性投入与月折旧。
  5. 设置配送方式：在「配送成本」页选择第三方平台或自配送，填写抽佣、配送费等参数。
  6. 创建菜品配方：在「菜品定价」页添加菜品，设置售价与预估日销量，展开「配方」从食材库选择食材并填写每份用量，食材成本自动联动。
  7. 查看综合看板：切回「综合看板」查看总投入、月固定成本、盈亏平衡点、预计月利润、成本结构饼图与菜品毛利排行。

❓ 常见问题

数据保存在哪里？ 保存在当前浏览器的 localStorage。更换浏览器或电脑前，请在「数据管理」页导出 JSON 备份，换环境后导入即可。

怎么在手机上 / 另一台电脑上继续用？ 分两步：① 把本 HTML 文件部署到免费静态托管（GitHub Pages、Netlify Drop、Vercel 均可直接拖入发布），手机浏览器打开网址即可使用；② 在「数据管理 → 数据同步」填写同一个同步地址并开启自动同步，各设备修改后自动互通，断网时仍用本地数据、联网后自动对齐。

同步地址从哪里来？ 推荐用你自己的 GitHub 仓库（永久免费，数据完全归你）：① 在「数据管理 → 数据同步」选择「GitHub 私有仓库」；② 仓库填「用户名/仓库名」（如 xt4nrjppw4-netizen/buycai-data），文件路径 data.json，分支 main；③ 生成访问令牌：登录 github.com → 头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → 勾选 repo 权限 → Generate token，复制 ghp_... 填入「访问令牌」（令牌只保存在浏览器本地，只此一次显示，请自己保管好）；④ 点「上传到云端」即可。之后随时打开 https://github.com/用户名/仓库名/blob/main/data.json 就能看到并下载云端数据。也可改用任何支持 GET / PUT 返回 JSON 的第三方接口（jsonblob.com 等）。

想直接改磁盘上的文件怎么办？ 用 Chrome / Edge 打开页面，在「数据管理 → 本地文件」点击「关联已有本地文件」或「新建本地数据文件」，之后每次修改都会自动写入该 JSON 文件；该文件可随时复制、备份或传到其他设备。

为什么米饭、豆浆等低价菜品净利为负？ 分摊成本按「出餐份数」均摊全部固定成本，低客单引流款会被摊高成本。这是该口径下的真实结果，可通过调价、提升出餐量或改按售价比例分摊来调整经营策略。

修改食材单价后菜品成本会变吗？ 会。所有输入实时联动：改单价、净料率、用量、固定成本、配送参数，菜品成本、毛利、看板全部自动刷新。

如何重新开始？ 「数据管理」页可一键恢复示例数据或清空全部数据。
